# TechnoPrime Brand Assets

Drop source files here. Suggested structure:

- `logo/`    primary logo (SVG/PNG), dark/light variants
- `cards/`   promo cards / social banners
- `social/`  avatars, story layouts, social sizes
- `inbox/`   raw uploads (move into folders above once sorted)

If you add new assets, prefer high-res PNG or SVG.
